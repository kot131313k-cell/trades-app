# AGENTS.md — правила для агента и человека

1. Обращения к хранилищу — только через функции из `storage.js`, нигде больше.
2. Различия между профессиями задаются данными в `profiles.js`. Никаких проверок вида «если электрик» в коде экранов.
3. Деньги — целыми копейками (минимальные единицы), никогда float для хранения. Даты — `ГГГГ-ММ-ДД`.
4. Статус «Просрочен» не хранится, а вычисляется при показе: `выставлен && срок < сегодня`.
5. Выставленный счёт неизменен: строки копируются в счёт, правка работы его не меняет. Исправление — новый счёт.
6. Номера счетов `ГОД-Порядковый` (например `2026-014`), без дублей.
7. Интерфейс: основное действие — большим пальцем внизу; кнопки ≥48px с запасом; крупный шрифт, высокий контраст; формы короткие; действие с деньгами — с подтверждением и видимой суммой.
8. Каждая задача: контекст → цель → границы (сверить с README) → крайние случаи (пусто/текст вместо цены/отрицательное/длинное) → проверка (телефон, консоль без ошибок, перезагрузка, два предыдущих сценария).
9. Не добавлять функции из правой колонки границ README («заодно») без явного решения человека.
