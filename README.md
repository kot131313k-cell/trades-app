# Trades App — приложение мастера: счета, долги, допуски

Приложение помогает мастеру выставить счёт сразу после работы, видеть неоплаченное и не пропускать сроки допусков.

## Границы первой версии

| Входит в первую версию | Не входит и почему |
| --- | --- |
| Клиенты и адреса объектов | Импорт контактов телефона — отдельный слой сложности |
| Записи о выполненных работах | Планировщик и календарь — это другой продукт |
| Счета со статусами и суммами | Онлайн-оплата картой — договоры, комиссии, проверки |
| Напоминания о неоплаченных счетах | Автоматическая рассылка клиентам — риск спама и расходы |
| Сроки допусков и сертификатов | Готовые формы отчётности госорганов — разные страны и правила |
| Счёт в виде файла для отправки | Бухгалтерия, налоги, зарплаты — ответственность слишком высока |
| Работа одного мастера | Бригады, роли, распределение заявок — позже |

Это учёт для себя и напоминания, а не бухгалтерия и не гарантия соответствия требованиям.

## Запуск

Без сборки. Откройте `index.html` в браузере телефона/ПК или опубликуйте как статический сайт:

```sh
# локально
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Данные хранятся локально в браузере (localStorage, ключ `trades-app-v1`).
Экспорт/импорт — на главном экране внизу («Резервная копия»).

## Тесты

```sh
node tests-core.js
```

Если Node нет — откройте `test-browser.html` в браузере (или headless Edge:
`msedge --headless --dump-dom test-browser.html`): 23 проверки —
сумма со скидкой, просрочка, номера счетов, сквозная цепочка через `Store`.

## Структура

- `index.html` — 6 экранов: Главная, Клиенты, Карточка клиента, Счёт, Счета/Долги, Допуски.
- `styles.css` — мобильный по умолчанию, крупные кнопки, контраст, печать счёта.
- `app.js` — экраны и формы. Хранилище только через `Store`.
- `storage.js` — единственный файл доступа к данным (localStorage сейчас, база с этапа F).
- `profiles.js` — различия профессий данными, без `if (электрик)` в экранах.
- `manifest.json`, `sw.js` — установка на главный экран + базовый офлайн.
